## Задание 23. VPN

### Файлы

`Vagrantfile` создает две ВМ: `vpn-server` и `vpn-client`. На сервер проброшен UDP-порт `1194`, через который подключается клиент с локальной машины.

`ansible/playbook.yml` устанавливает OpenVPN и iperf3, создает центр сертификации и сертификаты, настраивает TUN, TAP и RAS.

### Схема

| Режим | Сервер | Клиент | Порт |
| --- | --- | --- | --- |
| TUN | `10.8.0.1/24` | `10.8.0.2/24` | UDP `1194` |
| TAP | `10.9.0.1/24` | `10.9.0.100/24` | UDP `1195` |

ВМ обмениваются трафиком по сети `192.168.56.0/24`. TUN использует IP-уровень, TAP передает Ethernet-кадры через мост `br-tap` на сервере.

Для RAS создан отдельный сертификат `mac-client`. Временный профиль с сертификатами Ansible сохраняет вне репозитория: `/private/tmp/otus23/ras-client.ovpn`.

### Реализация

Сертификаты создаются через Easy-RSA на `vpn-server`. Сервер одновременно принимает TUN-клиентов на UDP `1194` и TAP-клиентов на UDP `1195`.

TUN используется для маршрутизации IP-трафика. TAP передает Ethernet-кадры через мост `br-tap` и подходит, когда нужен второй уровень сети.

### Замер скорости

Замер сделан `iperf3` по TCP в течение 10 секунд от `vpn-client` к `vpn-server`.

| Режим | Полученная скорость |
| --- | --- |
| TUN | `229.7 Мбит/с` |
| TAP | `222.0 Мбит/с` |

В этом стенде TUN оказался быстрее на `7.7 Мбит/с`, или примерно на `3.3%`. У TAP меньше TCP MSS: `1242` байта против `1274` у TUN. На результат влияют и накладные расходы Ethernet, и работа VirtualBox, поэтому это сравнение относится именно к этому стенду, а не к любому OpenVPN-серверу.

### RAS

Для RAS создан отдельный сертификат `mac-client`. Проверка выполнена с Mac: профиль подключился к серверу через проброшенный UDP-порт `1194`, а `10.8.0.1` ответил на два ping без потерь.

### Запуск

```bash
vagrant up
```

### Проверка

Состояние туннелей на клиенте:

```bash
vagrant ssh vpn-client -c 'ip -br address show tun0; ip -br address show tap0'
```

Скорость TUN:

```bash
vagrant ssh vpn-server -c 'iperf3 -s -D -p 5201'
vagrant ssh vpn-client -c 'iperf3 -c 10.8.0.1 -p 5201 -t 10'
```

Скорость TAP:

```bash
vagrant ssh vpn-client -c 'iperf3 -c 10.9.0.1 -p 5201 -t 10'
```

Профиль RAS подключается с Mac к проброшенному UDP-порту `1194`:

```bash
sudo /opt/homebrew/opt/openvpn/sbin/openvpn --config /private/tmp/otus23/ras-client.ovpn
```

После подключения сервер доступен по адресу `10.8.0.1`.

`ocserv` не настраивался: это дополнительная часть задания.
